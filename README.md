# Currency Converter

A React-based currency conversion interface built as a frontend practice project.

## Highlights

- Reusable currency converter component
- Interactive amount and currency inputs
- Component-based React structure
- Responsive styling

## Tech Stack

- React 18
- JavaScript
- CSS
- Create React App

## Run Locally

```bash
git clone https://github.com/eduardolluis/Currency-Converter.git
cd Currency-Converter
npm install
npm start
```

Create a production build with:

```bash
npm run build
```
